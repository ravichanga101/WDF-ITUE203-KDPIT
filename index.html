Course Description

This course covers the basics of the Internet, building a web application, databases, performance and security. It includes an extensive set of practical tutorials that help students get a feel for real-world development.

Pre-requisites: Overview of programming concepts; basic HTML elements (headings, paragraphs, links, images) and CSS styling (colors, fonts, layouts).

Course Objectives

  • Equip students with a strong foundation in web development by teaching the core concepts of HTML, CSS, and JavaScript to create responsive and interactive web pages.
  • Learn to create robust and scalable back-end systems using PHP, a widely-used server-side scripting language.
  • Integrate front-end and back-end components to build complete, data-driven web applications.
  • Apply best practices for security, including input validation, password hashing, and protection against SQL injection.

Course Outcomes

  • CO-1: Design and develop responsive and interactive web application using Hypertext Markup Language elements, forms, multimedia, and layouts.
  • CO-2: Demonstrate Cascading Style Sheets styling techniques such as selectors, text formatting, page formatting, and box model concepts to enhance the presentation of web pages.
  • CO-3: Implement dynamic behaviours and user interactions using JavaScript (ES6) features, including conditional branching, loops, functions, and operators.
  • CO-4: Manipulate the Document Object Model to create, update, or remove elements and add interactivity to web applications through event handling.
  • CO-5: Demonstrate server-side functionality, including handling forms, managing sessions and cookies, and implementing Object-Oriented Programming principles.
