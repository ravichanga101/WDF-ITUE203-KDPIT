# WDF — Web Development Frameworks (ITUE203)

Course website for **Web Development Frameworks (ITUE203)**.

**Smt. Kundanben Dinsha Patel Department of Information Technology**
Faculty of Technology & Engineering, Charotar University of Science & Technology (CHARUSAT)

**Faculty:** Ravi Patel, Dhaval Patel, Priyam Mehta

## Pages

- `index.html` — Home (course description, objectives, outcomes, syllabus, practical list, teaching scheme, faculty)
- `course-planning.html` — Lesson planning sheet & unit-wise plan
- `theory-assessment.html` — Theory assessment scheme & question papers
- `practical-assessment.html` — List of practicals & continuous assessment scheme
- `material.html` — Course materials, reference links & recommended books

## Editing content

This is a plain HTML/CSS site — no build step. Open any `.html` file in a
text editor and change the text directly. Shared styling lives in
`css/style.css`. The department logo is at `assets/logo.png`.

## Repository

This site is published at:
`https://github.com/ravichanga101/WDF-ITUE203-KDPIT`

## Deploy to GitHub Pages

1. On GitHub, go to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
4. Your site will be live in a minute or two at:
   `https://ravichanga101.github.io/WDF-ITUE203-KDPIT/`

To update the site later, edit the files and run:

```bash
git add .
git commit -m "Update content"
git push
```
